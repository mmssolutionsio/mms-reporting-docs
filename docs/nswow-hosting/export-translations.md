# translations_hosting.json

Basic Translation file for [VueI18n](https://vue-i18n.intlify.dev/). Generated by the `Text snippets` Tab in ns.wow Hosting.

## Structure

```json
{
  "de": {
    "my": {
      "path": "Hallo Welt"
    }
  },
  "en": {
    "my": {
      "path": "Hello world"
    }
  }
}
```
