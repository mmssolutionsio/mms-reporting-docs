# settings.json
Generated with the structure below. ns.wow Hosting only overwrites these generated entries, the rest **stays untouched**.

## Structure

```json
{
    "version": "v1.0",
    "defaultLanguage": "de",
    "languages": [
        "de",
        "en"
    ],
    "publicationName": { 
        "de": "publication name de",
        "en": "publication name en"
    }
}
```
